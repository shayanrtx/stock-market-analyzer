# Stock Market Analyzer — دستیار سبدگردان بورس تهران

<div dir="rtl">

سامانه‌ی تحت وب و چندکاربره‌ی مدیریت سبد سهام برای بورس و فرابورس تهران، با PHP و قابل نصب روی هاست اشتراکی.
داده‌ها از `cdn.tsetmc.com` و `webgw.tse.ir` گرفته می‌شوند (مرجع:
[BabakEslami/tse-market-data](https://github.com/BabakEslami/tse-market-data/blob/main/ENDPOINTS.md)).

> ⚠️ **سرورهای بورس فقط به IP ایران پاسخ می‌دهند.** برنامه را روی **هاست داخل ایران** نصب کنید. برای آشنایی
> بیرون از ایران، «حالت نمایشی» با داده‌ی ساختگی هم وجود دارد (پایین‌تر).

## نصب روی هاست (cPanel / DirectAdmin)

**پیش‌نیاز:** PHP نسخه‌ی ۸٫۱ یا جدیدتر با افزونه‌های `pdo_sqlite` (یا `pdo_mysql`)، `curl` و `mbstring`.
افزونه‌ی `gd` اختیاری است و فقط برای تصویر سیگنال‌ها لازم است. نسخه‌ی PHP را در کنترل‌پنل
(Select PHP Version یا MultiPHP Manager) انتخاب کنید.

۱. محتوای پوشه‌ی `app` را در `public_html` آپلود کنید، یا در یک زیرپوشه مثل `public_html/portfolio`.
   پوشه‌های `config` و `storage` باید قابل نوشتن باشند (دسترسی 755 یا 775).

۲. آدرس سایت را در مرورگر باز کنید. نصب‌کننده پیش‌نیازها را بررسی می‌کند. پایگاه داده را انتخاب کنید
   (SQLite بدون هیچ تنظیمی کار می‌کند؛ برای MySQL ابتدا در کنترل‌پنل دیتابیس بسازید) و حساب مدیر را بسازید.

۳. **زمان‌بند (Cron):** در بخش Cron Jobs کنترل‌پنل یک کار با زمان‌بندی «هر دقیقه» (<span dir="ltr">`* * * * *`</span>) بسازید.
   دستور دقیق، همراه با مسیر واقعی هاست شما، در «مدیریت سامانه ← تنظیمات سامانه» نمایش داده می‌شود:

   <div dir="ltr">

   ```
   /usr/local/bin/php /home/USER/public_html/bin/cron.php >/dev/null 2>&1
   ```

   </div>

   بدون Cron هم برنامه کار می‌کند، ولی رصد فقط تا وقتی صفحه‌ی «رصد زنده» باز است انجام می‌شود و سیگنال‌ها در غیاب
   شما به بله و تلگرام نمی‌رسند.

۴. در «مدیریت سامانه ← سلامت سامانه» همه‌ی سرویس‌های داده را آزمایش کنید. اگر فیلدی «ناموجود» گزارش شد،
   ساختار پاسخ بورس تغییر کرده است.

**امنیت:** فایل‌های `.htaccess` دسترسی مستقیم به `src`، `views`، `config`، `storage` و بقیه‌ی پوشه‌های داخلی را می‌بندند.
در Nginx معادل این قانون را اضافه کنید:

<div dir="ltr">

```nginx
location ~ ^/(src|views|storage|config|resources|tests|bin)/ { deny all; }
location / { try_files $uri /index.php?$query_string; }
```

</div>

`config/config.php` (رمز پایگاه داده و توکن Cron) را هرگز در گیت قرار ندهید؛ در `.gitignore` آمده است.

## اتصال ربات بله و تلگرام

۱. در بله به <span dir="ltr">`@botfather`</span> و در تلگرام به <span dir="ltr">`@BotFather`</span> پیام دهید، با دستور
   <span dir="ltr">`/newbot`</span> ربات بسازید و توکن را بگیرید.
۲. توکن و نام کاربری ربات را در «مدیریت سامانه ← تنظیمات سامانه» وارد کنید.
۳. هر کاربر در «تنظیمات و اعلان‌ها» روی «اتصال به بله» می‌زند، در ربات «شروع» را می‌فرستد و «بررسی اتصال» را می‌زند.
   حداقل احتمال موفقیت سیگنال‌های دریافتی را هم همان‌جا تعیین می‌کند.

سرورهای داخل ایران معمولاً به تلگرام دسترسی ندارند؛ بله بدون مشکل کار می‌کند.

## اجرای محلی و حالت نمایشی (مثلاً در VS Code)

حالت نمایشی یک بازار ساختگی ولی منطقی می‌سازد (دامنه‌ی نوسان ±۵٪، افزایش سرمایه، سود نقدی، صف خرید و فروش،
ساعت پیش‌گشایش و معاملات) تا بتوانید همه‌ی بخش‌ها را بیرون از ایران ببینید. در بالای همه‌ی صفحه‌ها نوار
«حالت نمایشی» نشان داده می‌شود.

<div dir="ltr">

```bash
cd app
php bin/demo.php                  # config + database in demo mode, a sample account, 13 replayed sessions
php -S localhost:8000 index.php   # open http://localhost:8000  — user: demo  password: demo1234
```

</div>

برای داده‌ی واقعی، `config/config.php` را پاک کنید و نصب‌کننده را دوباره اجرا کنید (یا در آن
<span dir="ltr">`'transport' => 'curl'`</span> بگذارید)، و برنامه را روی سیستم یا سرور داخل ایران اجرا کنید.

## تست‌ها

تست‌ها بدون Composer و PHPUnit اجرا می‌شوند. HTTP و جداسازی داده‌ی کاربران، موتور رصد زنده، اعلان‌ها،
کارنامه‌ی سیگنال‌ها، پیشنهادهای سبدگردانی، تشخیص نوع ابزار، تقویم شمسی و بازار نمایشی را پوشش می‌دهند. اندیکاتورها
و امتیاز پتانسیل هم با نسخه‌ی پایتون به‌صورت عددی مقایسه می‌شوند:

<div dir="ltr">

```bash
php app/tests/run.php
```

</div>
