# Stock Market Analyzer — تحلیلگر بورس تهران

<div dir="rtl">

سیستم تحلیل بورس و فرابورس تهران شامل داشبورد وب، ابزار خط فرمان و کتابخانه‌ی پایتون، روی API غیررسمی
`cdn.tsetmc.com` و گیت‌وی رسمی `webgw.tse.ir`. مرجع endpointها:
[BabakEslami/tse-market-data — ENDPOINTS.md](https://github.com/BabakEslami/tse-market-data/blob/main/ENDPOINTS.md)

> ⚠️ **سرورهای بورس فقط به اتصال داخل ایران جواب می‌دهند.** موقع نصب می‌توانید VPN داشته باشید،
> ولی موقع اجرا **VPN باید خاموش باشد.**

## شروع سریع

پیش‌نیاز: [Python 3.10 یا جدیدتر](https://www.python.org/downloads/). در ویندوز موقع نصب، تیک
«Add python.exe to PATH» را بزنید.

۱. ریپو را دانلود کنید: دکمه‌ی سبز **Code** و بعد **Download ZIP**، یا با `git clone`.

۲. اجرا:

| سیستم‌عامل | داشبورد | تست اتصال |
|---|---|---|
| ویندوز | دوبار کلیک روی `run.bat` | `run.bat doctor` در CMD |
| لینوکس/مک | `./run.sh` | `./run.sh doctor` |

بار اول، محیط مجازی پایتون ساخته و پکیج‌ها نصب می‌شوند. بعد داشبورد در آدرس
<span dir="ltr">`http://127.0.0.1:8000`</span> باز می‌شود.

## اولین کار: تست اتصال (`doctor`)

این نسخه از خارج از ایران و بدون دسترسی به API نوشته شده است. اسم فیلدهای پاسخ‌ها بر اساس مستندات و
تجربه گذاشته شده، ولی هنوز با پاسخ واقعی تأیید نشده است. پس اول این را اجرا کنید:

```bash
tse-analyzer doctor
```

این دستور تمام endpointهایی را که برنامه استفاده می‌کند صدا می‌زند و نتیجه را این‌طور نشان می‌دهد:

```
OK              cdn_search                     12
MISSING_FIELDS  cdn_client_type                 1  missing: buy_CountI
ERROR           gw_market_summary               0  HTTP 403 for ...
```

نمونه‌ی کوچکی از هر پاسخ هم در پوشه‌ی `diagnostics/` ذخیره می‌شود. اگر نتیجه‌ای غیر از `OK` دیدید،
محتوای این پوشه را بفرستید تا کد اصلاح شود.

## امکانات

**داشبورد وب** (`tse-analyzer serve`)
- صفحه‌ی اصلی: خلاصه‌ی بازار، شاخص‌های بورس و فرابورس، و نمادهای با بیشترین اثر روی شاخص کل
- صفحه‌ی هر نماد: نمودار قیمت با SMA50 و SMA200، بازدهی، اندیکاتورها، حقیقی/حقوقی، سیگنال‌ها و جمع‌بندی
- اسکنر پول هوشمند و فهرست بیشترین رشد
- بدون وابستگی به CDN خارجی، پس در اینترنت داخلی هم کامل باز می‌شود. تم روشن و تیره دارد و در موبایل هم درست نمایش داده می‌شود.
- API با خروجی JSON: <span dir="ltr">`/api/stock?symbol=فولاد`</span>

**پرتفوی من** (صفحه‌ی «پرتفوی من» در داشبورد، یا `tse-analyzer portfolio`)
- لیست دارایی‌ها را از جدول کارگزاری کپی کنید و در داشبورد بچسبانید. هر خط: `نماد تعداد [میانگین خرید به ریال]`
- ارزش کل، سود/زیان امروز، و سود/زیان از قیمت خرید (اگر وارد شده باشد)
- برای هر نماد: قیمت، تغییر امروز، وزن در پرتفو، سیگنال و قدرت خریدار حقیقی
- ترکیب صنعت و ریسک ترکیب فعلی (نوسان سالانه، بیشترین افت، بازده یک ماه، سه ماه و یک سال)
- هشدار برای تمرکز بالا روی یک نماد (بیش از ۲۵٪) یا یک صنعت (بیش از ۴۰٪)، نماد متوقف، سیگنال نزولی و اشباع خرید
- پرتفو فقط روی کامپیوتر خودتان در فایل `portfolio.csv` ذخیره می‌شود و وارد گیت نمی‌شود.

**تحلیل نماد**
- میانگین متحرک ۲۰، ۵۰ و ۲۰۰، RSI، MACD، باند بولینگر، ATR، و نسبت حجم به میانگین
- بازدهی یک هفته، یک ماه، سه ماه، شش ماه و یک سال
- سرانه‌ی خرید و فروش حقیقی، قدرت خریدار، ورود پول حقیقی و سهم خرید حقوقی
- امتیازدهی سیگنال‌ها از «نزولی قوی» تا «صعودی قوی»
- نمایش وضعیت نماد (مجاز یا متوقف)

**اسکنر کل بازار**
- ورود پول هوشمند: نمادهایی که قدرت خریدار حقیقی‌شان امروز بالاست (از `GetClientTypeAll`)
- بیشترین رشد یا افت، یا بیشترین ارزش معاملات (از دیده‌بان رسمی `MarketWatchCash`)

## دستورات خط فرمان

```bash
tse-analyzer serve                         # داشبورد وب
tse-analyzer doctor                        # تست اتصال و ساختار پاسخ‌ها
tse-analyzer search فولاد                  # جستجوی نماد
tse-analyzer analyze فولاد شپنا خودرو      # تحلیل یک یا چند نماد
tse-analyzer analyze فولاد --days 0        # با کل تاریخچه
tse-analyzer market                        # شاخص‌های بورس
tse-analyzer market --farabourse --all     # همه‌ی شاخص‌های فرابورس
tse-analyzer portfolio                     # تحلیل پرتفو از فایل portfolio.csv
tse-analyzer screen                        # ورود پول هوشمند
tse-analyzer screen --movers               # بیشترین رشد
tse-analyzer screen --movers --losers      # بیشترین افت
tse-analyzer screen --movers --by trade_value
tse-analyzer --json analyze فولاد          # خروجی JSON
```

پاسخ‌ها ۵ دقیقه در پوشه‌ی `.cache/` نگه داشته می‌شوند. برای غیرفعال کردن کش از `--cache-dir ""` استفاده کنید.

نصب دستی به‌جای اسکریپت‌های `run`:

```bash
python -m venv .venv
.venv\Scripts\activate          # ویندوز
source .venv/bin/activate       # لینوکس/مک
pip install -e ".[dev]"
```

## استفاده به‌عنوان کتابخانه

```python
from tse_analyzer import TsetmcClient
from tse_analyzer.analysis import fetch_and_analyze

client = TsetmcClient(cache_dir=".cache")
result, history = fetch_and_analyze(client, "فولاد")
print(result.verdict, result.score)
print(history.tail())          # DataFrame: open/high/low/close/volume/...
```

## ساختار پروژه

| فایل | کارکرد |
|---|---|
| `tse_analyzer/client.py` | کلاینت HTTP برای `cdn.tsetmc.com` و `webgw.tse.ir`: هدرها، retry با backoff، و کش |
| `tse_analyzer/indicators.py` | اندیکاتورهای تکنیکال با pandas |
| `tse_analyzer/analysis.py` | جریان پول حقیقی/حقوقی، سیگنال‌ها و جمع‌بندی |
| `tse_analyzer/screener.py` | اسکنرهای کل بازار |
| `tse_analyzer/portfolio.py` | تحلیل پرتفو: ارزش، سود/زیان، ترکیب صنعت و ریسک |
| `tse_analyzer/doctor.py` | تست اتصال و بررسی فیلدها |
| `tse_analyzer/web.py` | داشبورد وب، فقط با کتابخانه‌ی استاندارد پایتون |
| `tse_analyzer/report.py` | خروجی متنی و JSON |
| `tse_analyzer/cli.py` | دستورات خط فرمان |

## نکات

- API سایت tsetmc غیررسمی است و ممکن است بدون اطلاع قبلی تغییر کند. در این صورت `doctor` را دوباره اجرا کنید.
- اگر نماد متوقف باشد، داده‌ی خالی یا خطای ۵۰۰ طبیعی است.
- تاریخچه‌ی قیمت برای افزایش سرمایه و سود نقدی **تعدیل نشده** است. اگر نمادی در بازه‌ی بررسی افزایش سرمایه
  داشته باشد، بازده و اندیکاتورهای آن یک افت مصنوعی نشان می‌دهند.
- داشبورد فقط روی `127.0.0.1` باز است. برای دسترسی از گوشی در همان شبکه از `--host 0.0.0.0` استفاده کنید.
- **این ابزار توصیه‌ی سرمایه‌گذاری نیست.**
