# Stock Market Analyzer — دستیار سبدگردان بورس تهران

<div dir="rtl">

دستیار تحلیل و مدیریت سبد سهام برای بورس و فرابورس تهران. شامل داشبورد وب، رصد زنده‌ی بازار، ابزار خط فرمان و
کتابخانه‌ی پایتون است و داده‌هایش را از `cdn.tsetmc.com` (غیررسمی) و `webgw.tse.ir` (رسمی) می‌گیرد.
مرجع endpointها: [BabakEslami/tse-market-data](https://github.com/BabakEslami/tse-market-data/blob/main/ENDPOINTS.md)

> ⚠️ **سرورهای بورس فقط به اتصال داخل ایران پاسخ می‌دهند.** موقع نصب می‌توانید VPN داشته باشید، ولی موقع
> اجرا **VPN باید خاموش باشد.**

## شروع سریع

پیش‌نیاز: [Python 3.10 یا جدیدتر](https://www.python.org/downloads/). در ویندوز موقع نصب، تیک
«Add python.exe to PATH» را بزنید.

| سیستم‌عامل | داشبورد | تست اتصال |
|---|---|---|
| ویندوز | دوبار کلیک روی `run.bat` | `run.bat doctor` در CMD |
| لینوکس/مک | `./run.sh` | `./run.sh doctor` |

در VS Code پوشه‌ی اصلی پروژه را باز کنید (همان پوشه‌ای که `run.bat` در آن است، نه پوشه‌ی `tse_analyzer`).
بعد از منوی Terminal → New Terminal دستور `.\run.bat` را بزنید. داشبورد در آدرس
<span dir="ltr">`http://127.0.0.1:8000`</span> باز می‌شود.

## اولین کار: `doctor`

این نسخه بیرون از ایران و بدون دسترسی به API نوشته و با داده‌ی ساختگی تست شده است. اسم بعضی از فیلدها
(تاریخچه‌ی شاخص، حقیقی/حقوقی روزانه، EPS و دامنه‌ی نوسان) هنوز با پاسخ واقعی تأیید نشده‌اند. اول این را اجرا کنید:

```bash
tse-analyzer doctor
```

این دستور همه‌ی endpointهای مورد استفاده را تست می‌کند و نمونه‌ی پاسخ‌ها را در `diagnostics/` ذخیره می‌کند. اگر
نتیجه‌ای غیر از `OK` دیدید، محتوای آن پوشه را بفرستید.

## صفحه‌های داشبورد

**سبد من** (صفحه‌ی اصلی)
- **شاخص‌های کلیدی:** ارزش سبد (NAV)، سود/زیان امروز و از خرید، بازده ۱ و ۳ ماهه و ۱ ساله در برابر شاخص کل،
  نوسان، بتا، بیشترین افت، نسبت شارپ، ارزش در معرض خطر روزانه (VaR ۹۵٪) و تعداد مؤثر نمادها
- **نمودارها:**
  - منحنی بازده سبد در برابر شاخص کل، همراه با نمودار افت از سقف
  - ترکیب سبد به تفکیک نماد، صنعت و نوع دارایی
  - وزن هر نماد در برابر سهمش از ریسک سبد
  - ماتریس همبستگی نمادها
  - نقشه‌ی ریسک و بازده
- **پیشنهادهای مدیریت سبد:** برای هر نماد یکی از اقدام‌های افزایش، نگهداری، کاهش یا خروج تدریجی، همراه با
  وزن پیشنهادی، مبلغ تقریبی معامله و دلیل
- **جدول دارایی‌ها:** پتانسیل رشد، فاصله تا هدف، حد ضرر، پاداش به ریسک، چند جلسه طول می‌کشد موقعیت فروخته
  شود، سهم از ریسک، قدرت خریدار و صف (قابل مرتب‌سازی)
- **هشدارها:** تمرکز بالا، صف فروش، نقدشوندگی پایین، عبور از حد ضرر و پتانسیل رشد ضعیف

**تحلیل نماد**
- نمودار شمعی همراه با میانگین‌های ۲۰، ۵۰ و ۲۰۰ روزه، باند بولینگر، حجم، RSI و MACD (با زوم)
- امتیاز پتانسیل رشد (۰ تا ۱۰۰)، احتمال رشد ۳ ماهه و یک جمع‌بندی تحلیلی
- سهم هر عامل در امتیاز (نمودار) و دلایل تخصصی، به تفکیک فنی، جریان پول، بنیادی و آماری
- سه سناریوی بدبینانه، پایه و خوش‌بینانه برای ۳ ماه آینده، و توزیع بازده موقعیت‌های مشابه تاریخی
- جریان پول حقیقی در ۶۰ جلسه‌ی اخیر، سطوح قیمتی، ارزش‌گذاری، بازده سال‌های شمسی و نمودار افت از سقف

**بازار:** شاخص‌ها، نمودار شاخص کل، پهنای بازار، نقشه‌ی حرارتی صنایع، نمادهای اثرگذار، و بیشترین رشد، افت و
ارزش معاملات.

**رصد زنده:** پایین‌تر توضیح داده شده است.

**اسکنر:** ورود پول هوشمند در کل بازار و بیشترین رشد.

## رصد زنده

از ۸:۴۵ صبح باز بگذارید. هر ۴۵ ثانیه همه‌ی نمادهای سبد و دیده‌بان را بررسی می‌کند و رویدادهای مهم را در
«جریان بینش‌ها» نشان می‌دهد. برای هشدارهای فوری اعلان مرورگر هم می‌دهد (دکمه‌ی «فعال‌سازی اعلان»).

| فاز | ساعت | چه چیزی رصد می‌شود |
|---|---|---|
| پیش‌گشایش | ۸:۴۵ تا ۹:۰۰ | سفارش‌های ثبت‌شده: احتمال بازگشایی با صف خرید یا فروش، و قیمت تقریبی بازگشایی |
| معاملات پیوسته | ۹:۰۰ تا ۱۲:۳۰ | همه‌ی قواعد جدول زیر |
| معاملات پایانی | ۱۲:۴۵ تا ۱۳:۰۰ | وضعیت قیمت‌ها |

| قاعده | شناسایی |
|---|---|
| `queue` | شکل‌گیری صف خرید یا فروش و سنگینی آن نسبت به میانگین ارزش معاملات روزانه |
| `queue_change` | شکسته شدن یا ریختن صف خرید، جمع شدن صف فروش، تقویت صف |
| `imbalance` | برتری حجم سفارش‌های خرید یا فروش در ۵ سطح اول تابلو |
| `pre_open` | برآورد بازگشایی از تابلوی پیش‌گشایش |
| `smart_money` | ورود یا خروج پول هوشمند (قدرت خریدار حقیقی در طول روز) |
| `volume_pace` | حجم مشکوک: حجم تا این ساعت در برابر حجم عادی در همان ساعت |
| `levels` | شکست سقف دیروز یا سقف ۵۲ هفته، رسیدن به هدف، عبور از حد ضرر |
| `fast_move` | جهش یا افت سریع قیمت در ۱۰ دقیقه |
| بازار | حرکت قابل توجه شاخص کل |

هشدارهای تکراری تا ۱۵ دقیقه نمایش داده نمی‌شوند، مگر شدیدتر شوند. نماد اضافه برای رصد را از همان صفحه به
دیده‌بان اضافه کنید. در ترمینال هم با `tse-analyzer live` اجرا می‌شود.

## روش تحلیل

**پتانسیل رشد** (`potential.py`): امتیاز برابر است با ۵۰ به‌علاوه‌ی مجموع اثر وزن‌دار این عامل‌ها:

| عامل | دسته | وزن |
|---|---|---|
| روند اولیه: قیمت نسبت به SMA200 و شیب آن | فنی | ۲ |
| الگوهای مشابه تاریخی: بازده ۳ ماه بعد در موقعیت‌هایی با روند، RSI و فاصله از سقف مشابه | آماری | ۲ |
| روند ثانویه: تقاطع طلایی یا مرگ، و قیمت نسبت به SMA50 | فنی | ۱.۵ |
| ارزش‌گذاری: P/E در برابر صنعت، و بازده سود (E/P) در برابر نرخ بدون ریسک | بنیادی | ۱.۵ |
| مومنتوم واقعی ۶ ماهه (پس از کسر تورم) | فنی | ۱ |
| قدرت نسبی در برابر شاخص کل | فنی | ۱ |
| موقعیت در دامنه‌ی ۵۲ هفته | فنی | ۱ |
| کشش قیمت (RSI و فاصله از SMA50) | فنی | ۱ |
| انباشت یا توزیع حجم | فنی | ۱ |
| جریان پول حقیقی (۲۰ جلسه) | جریان پول | ۱ |
| رژیم نوسان (فشردگی باند بولینگر) | فنی | ۰.۵ |
| نقدشوندگی | جریان پول | ۰.۵ |

- **سناریوها:** صدک‌های ۲۰، ۵۰ و ۸۰ بازده ۳ ماه بعد در موقعیت‌های مشابه تاریخی.
- **حد ضرر:** ۲٪ زیر نزدیک‌ترین حمایت، به شرطی که در محدوده‌ی ۲.۵ برابر ATR باشد؛ در غیر این صورت ۲.۵ ATR
  زیر قیمت.
- **پاداش به ریسک:** فاصله تا مقاومت تقسیم بر فاصله تا حد ضرر.

**ریسک سبد** (`risk.py`): ترکیب فعلی سبد روی قیمت‌های تعدیل‌شده‌ی ۲۵۰ جلسه‌ی اخیر بازسازی می‌شود، و این
شاخص‌ها روی آن محاسبه می‌شوند:
- نوسان، بیشترین افت، شارپ و سورتینو (نسبت به نرخ بدون ریسک)
- بتا و همبستگی با شاخص کل
- ارزش در معرض خطر تاریخی و شرطی (VaR و CVaR ۹۵٪)
- سهم هر نماد از واریانس سبد، ماتریس همبستگی، نسبت تنوع‌بخشی و شاخص هرفیندال

**پیشنهاد اقدام** (`advisor.py`) این عوامل را ترکیب می‌کند:
- امتیاز پتانسیل رشد، احتمال تاریخی رشد و روند اولیه
- پاداش به ریسک
- سقف وزن هر نماد (۲۵٪)
- سهم از ریسک (اگر بیش از ۱.۵ برابر وزن نماد باشد، کاهش پیشنهاد می‌شود)
- نقدشوندگی (اگر خروج بیش از ۵ جلسه طول بکشد)

**تعدیل قیمت:** همه‌ی تحلیل‌ها روی قیمت تعدیل‌شده برای افزایش سرمایه و سود نقدی انجام می‌شوند. ضریب تعدیل از
اختلاف قیمت مرجع هر روز با قیمت پایانی روز قبل به دست می‌آید.

| متغیر | فایل | پیش‌فرض | معنا |
|---|---|---|---|
| `INFLATION_ANNUAL` | `potential.py` | ۰.۳۵ | تورم سالانه؛ معیار مقایسه‌ی بازده‌ها |

## توسعه

افزودن یک قاعده‌ی جدید به رصد زنده فقط یک تابع است:

```python
from tse_analyzer.live.rules import rule
from tse_analyzer.live.models import Insight
from tse_analyzer.live.session import Phase

@rule("big_trade_count", {Phase.CONTINUOUS}, "تعداد معاملات غیرعادی")
def big_trade_count(history, ctx, now):
    s = history[-1]
    if s.trades > 5000:
        return [Insight(s.at, s.symbol, "big_trade_count", 0, 2, "تعداد معاملات بالا", f"{s.trades:,.0f} معامله")]
    return []
```

| ماژول | کارکرد |
|---|---|
| `client.py` | کلاینت HTTP (هدرها، تکرار درخواست با backoff، کش)، تعدیل قیمت، نوع ابزار |
| `indicators.py` | اندیکاتورهای فنی |
| `analysis.py` | تحلیل تکنیکال و جریان پول یک نماد |
| `potential.py` | بررسی گذشته‌نگر، الگوهای مشابه، سناریوها و امتیاز پتانسیل رشد |
| `risk.py` | ریسک و عملکرد سبد |
| `advisor.py` | قواعد پیشنهاد اقدام |
| `portfolio.py` | تحلیل سبد (نقد، نقدشوندگی، صف، ریسک، پیشنهاد) |
| `live/` | موتور رصد زنده: فازهای بازار، تصویر لحظه‌ای، قواعد و موتور |
| `web/` | داشبورد: صفحه‌ها، نمودارها (ECharts)، فونت وزیرمتن، سرور |
| `screener.py`, `doctor.py`, `report.py`, `cli.py` | اسکنر، تست اتصال، خروجی متنی، خط فرمان |

## خط فرمان

```bash
tse-analyzer serve                         # داشبورد
tse-analyzer live                          # رصد زنده در ترمینال (نمادهای سبد)
tse-analyzer live فملی خودران --interval 30
tse-analyzer portfolio                     # تحلیل سبد از portfolio.csv
tse-analyzer potential فملی                # بررسی کامل و پتانسیل رشد
tse-analyzer analyze فولاد --days 0
tse-analyzer market | screen | search فولاد | doctor
tse-analyzer --json potential فملی         # خروجی JSON
```

**فرمت فایل سبد** (`portfolio.csv`، فقط روی کامپیوتر خودتان می‌ماند و وارد گیت نمی‌شود):

```
فملی    17673
خودران  10000   95000     ← میانگین خرید به ریال (اختیاری)
نقد     500000000         ← وجه نقد به ریال
```

## محدودیت‌ها

- API سایت tsetmc غیررسمی است و ممکن است بدون اطلاع قبلی تغییر کند. در این صورت `doctor` را دوباره اجرا کنید.
- امتیازها، احتمال‌ها و سناریوها جمع‌بندی آماری از گذشته‌اند. اخبار، صورت‌های مالی جدید و تصمیم‌های سیاسی و
  اقتصادی در آن‌ها دیده نمی‌شوند. **این ابزار کمک تصمیم است، نه توصیه‌ی قطعی سرمایه‌گذاری.**
- رصد زنده هر ۴۵ ثانیه داده می‌گیرد. برای اسکالپ ثانیه‌ای مناسب نیست.
