# Stock Market Analyzer — دستیار سبدگردان بورس تهران

<div dir="rtl">

سامانه‌ی تحت وب و چندکاربره‌ی مدیریت سبد سهام برای بورس و فرابورس تهران، با PHP و قابل نصب روی هاست اشتراکی.
داده‌ها از `cdn.tsetmc.com` و `webgw.tse.ir` (مرجع:
[BabakEslami/tse-market-data](https://github.com/BabakEslami/tse-market-data/blob/main/ENDPOINTS.md)) و نرخ دلار آزاد از
`api.tgju.org` گرفته می‌شود.

> ⚠️ **سرورهای بورس فقط به IP ایران پاسخ می‌دهند.** برنامه را روی **هاست داخل ایران** نصب کنید. برای آشنایی
> بیرون از ایران، «حالت نمایشی» با داده‌ی ساختگی هم وجود دارد (پایین‌تر).

## نصب روی هاست (cPanel / DirectAdmin)

**پیش‌نیاز:** PHP نسخه‌ی ۸٫۱ یا جدیدتر با افزونه‌های `pdo_sqlite` (یا `pdo_mysql`)، `curl` و `mbstring`.
افزونه‌ی `gd` اختیاری است و فقط برای تصویر سیگنال‌ها لازم است. نسخه‌ی PHP را در کنترل‌پنل
(Select PHP Version یا MultiPHP Manager) انتخاب کنید.

۱. محتوای پوشه‌ی `app` را در `public_html` آپلود کنید، یا در یک زیرپوشه مثل `public_html/portfolio`.
   پوشه‌های `config` و `storage` باید قابل نوشتن باشند (دسترسی 755 یا 775).

۲. آدرس سایت را در مرورگر باز کنید. نصب‌کننده پیش‌نیازها را بررسی می‌کند. پایگاه داده را انتخاب کنید
   (SQLite بدون هیچ تنظیمی کار می‌کند؛ برای MySQL ابتدا در کنترل‌پنل دیتابیس بسازید) و حساب مدیر را بسازید.

۳. **زمان‌بند (Cron):** در بخش Cron Jobs کنترل‌پنل یک کار با زمان‌بندی «هر دقیقه» بسازید (هر پنج فیلد
   <span dir="ltr">`*`</span>). دستور دقیق، همراه با مسیر واقعی هاست شما، در «مدیریت سامانه ← تنظیمات سامانه» نمایش
   داده می‌شود:

   <div dir="ltr">

   ```
   /usr/local/bin/php /home/USER/public_html/bin/cron.php
   ```

   </div>

   - <span dir="ltr">`>/dev/null 2>&1`</span> را اضافه نکنید؛ cPanel آن را «Command chaining operators are not allowed»
     می‌داند. لازم هم نیست: اسکریپت در اجرای عادی هیچ خروجی ندارد و خطاها را در <span dir="ltr">`storage/logs/cron.log`</span> می‌نویسد.
   - اگر هاست «هر دقیقه» را نپذیرفت، کمترین فاصله‌ی مجاز (مثلاً <span dir="ltr">`*/5`</span> در فیلد Minute) را بگذارید.
   - اگر ایمیلی با پیام «PHP … is too old» آمد، PHP خط فرمان هاست قدیمی است؛ مسیر نسخه‌ی ۸ را بگذارید، مثلاً
     <span dir="ltr">`/opt/cpanel/ea-php82/root/usr/bin/php`</span> یا <span dir="ltr">`/opt/alt/php82/usr/bin/php`</span>.
   - چند دقیقه بعد، ردیف «آخرین اجرای cron» در «سلامت سامانه» باید سبز شود.

   بدون Cron هم برنامه کار می‌کند، ولی رصد فقط تا وقتی صفحه‌ی «رصد زنده» باز است انجام می‌شود، سیگنال‌ها و هشدارها در غیاب
   شما به بله و تلگرام نمی‌رسند و پشتیبان روزانه ساخته نمی‌شود.

   Cron هر روز یک نسخه‌ی پشتیبان از پایگاه داده در <span dir="ltr">`storage/backups`</span> می‌سازد (۷ نسخه‌ی آخر نگه داشته می‌شود).
   از «سلامت سامانه» دانلودش کنید و یک نسخه را بیرون از هاست هم نگه دارید.

۴. در «مدیریت سامانه ← سلامت سامانه» همه‌ی سرویس‌های داده را آزمایش کنید. اگر فیلدی «ناموجود» گزارش شد،
   ساختار پاسخ بورس تغییر کرده است.

**امنیت:** فایل‌های `.htaccess` دسترسی مستقیم به `src`، `views`، `config`، `storage` و بقیه‌ی پوشه‌های داخلی را می‌بندند.
در Nginx معادل این قانون را اضافه کنید:

<div dir="ltr">

```nginx
location ~ ^/(src|views|storage|config|resources|tests|bin)/ { deny all; }
location / { try_files $uri /index.php?$query_string; }
```

</div>

`config/config.php` (رمز پایگاه داده و توکن Cron) را هرگز در گیت قرار ندهید؛ در `.gitignore` آمده است.

## اتصال ربات بله و تلگرام

۱. در بله به <span dir="ltr">`@botfather`</span> و در تلگرام به <span dir="ltr">`@BotFather`</span> پیام دهید، با دستور
   <span dir="ltr">`/newbot`</span> ربات بسازید و توکن را بگیرید.
۲. توکن و نام کاربری ربات را در «مدیریت سامانه ← تنظیمات سامانه» وارد کنید.
۳. هر کاربر در «تنظیمات و اعلان‌ها» روی «اتصال به بله» می‌زند، در ربات «شروع» را می‌فرستد و «بررسی اتصال» را می‌زند.
   حداقل احتمال موفقیت سیگنال‌های دریافتی و دریافت اطلاعیه‌های مهم را هم همان‌جا تعیین می‌کند.
۴. کاربرانی که پیام‌رسان متصل کرده‌اند، رمز فراموش‌شده را خودشان با «فراموش کرده‌اید؟» در صفحه‌ی ورود بازیابی می‌کنند:
   یک کد ۸ رقمی (۱۵ دقیقه اعتبار، حداکثر ۵ بار تلاش) به پیام‌رسانشان فرستاده می‌شود. برای بقیه، مدیر رمز را از «کاربران» عوض می‌کند.

سرورهای داخل ایران معمولاً به تلگرام دسترسی ندارند؛ بله بدون مشکل کار می‌کند.

## اجرای محلی و حالت نمایشی (مثلاً در VS Code)

حالت نمایشی یک بازار ساختگی ولی منطقی می‌سازد (دامنه‌ی نوسان ±۵٪، افزایش سرمایه، سود نقدی، صف خرید و فروش،
ساعت پیش‌گشایش و معاملات) تا بتوانید همه‌ی بخش‌ها را بیرون از ایران ببینید. در بالای همه‌ی صفحه‌ها نوار
«حالت نمایشی» نشان داده می‌شود.

<div dir="ltr">

```bash
cd app
php bin/demo.php                  # config + database in demo mode, a sample account, 13 replayed sessions
php -S localhost:8000 index.php   # open http://localhost:8000  — user: demo  password: demo1234
```

</div>

برای داده‌ی واقعی، `config/config.php` را پاک کنید و نصب‌کننده را دوباره اجرا کنید (یا در آن
<span dir="ltr">`'transport' => 'curl'`</span> بگذارید)، و برنامه را روی سیستم یا سرور داخل ایران اجرا کنید.

## تست‌ها

تست‌ها بدون Composer و PHPUnit اجرا می‌شوند. HTTP و جداسازی داده‌ی کاربران، موتور رصد زنده، اعلان‌ها، هشدار قیمت و
اطلاعیه، بازیابی رمز (بدون افشای وجود حساب و با محدودیت تلاش)، پشتیبان‌گیری، کارنامه‌ی سیگنال‌ها، پیشنهادهای سبدگردانی،
بازده اسناد خزانه، حباب صندوق، TWR و XIRR، برابری ریسک، روند بازار، بازه‌ی اطمینان، تشخیص نوع ابزار، تقویم شمسی و بازار
نمایشی را پوشش می‌دهند. اندیکاتورها و امتیاز پتانسیل هم با نسخه‌ی پایتون به‌صورت عددی مقایسه می‌شوند:

<div dir="ltr">

```bash
php app/tests/run.php
```

</div>

## نسخه‌ی پایتون (آزمایشگاه پژوهش)

ابزار خط فرمان و داشبورد محلی در پوشه‌ی `python` است (<span dir="ltr">`python/run.bat`</span> یا
<span dir="ltr">`python/run.sh`</span>، و دستور <span dir="ltr">`doctor`</span> برای آزمایش اتصال). همان تحلیل‌های نسخه‌ی PHP را دارد و
روی سیستم خودتان (داخل ایران) برای پژوهش روی داده‌ی تاریخی به کار می‌رود:

<div dir="ltr">

```bash
tse-analyzer store update --portfolio portfolio.csv --watchlist watchlist.txt --usd   # local SQLite price store
tse-analyzer research calibrate --out weights.json      # which factors actually predicted 3-month excess returns
tse-analyzer research signals                           # backtest of the buy filter, with and without the regime filter
tse-analyzer performance --ledger ledger.csv            # TWR / XIRR against TEDPIX, inflation and the risk-free rate
tse-analyzer rates      |  tse-analyzer funds --type 4  |  tse-analyzer news فملی
```

</div>

**وزن‌های کالیبره:** خروجی <span dir="ltr">`research calibrate`</span> را با نام <span dir="ltr">`weights.json`</span> در پوشه‌ی
<span dir="ltr">`config`</span> برنامه‌ی PHP بگذارید تا امتیاز پتانسیل رشد با وزن‌هایی که روی داده‌ی واقعی سنجیده شده‌اند حساب شود.
عاملی که شواهد آماری کافی نداشته باشد وزن پیش‌فرض (×۱) را نگه می‌دارد، و وضعیت فایل در «سلامت سامانه» نمایش داده می‌شود.
نام عامل‌ها در دو نسخه با یک تست مشترک هم‌خوان نگه داشته می‌شود.
